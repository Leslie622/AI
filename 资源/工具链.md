# 工具链

> 只列会在本路线实际用到/需要知道的。原则：先裸写 API，再上轻 SDK，最后才考虑框架。
> "章"列对应 [知识大纲.md](../知识大纲.md) 的章号。

## 模型 API（OpenAI 兼容协议优先）

| 工具 | 用途 |
|---|---|
| [DeepSeek](https://platform.deepseek.com/) / [智谱 GLM](https://open.bigmodel.cn/) / [硅基流动](https://siliconflow.cn/) | 国内可直连、注册送额度的起点；毕业项目可任选为默认模型 |
| [OpenRouter](https://openrouter.ai/) | 一个 key 调多家模型，做对比实验方便 |
| [OpenAI](https://platform.openai.com/) / [Anthropic](https://console.anthropic.com/) / [Google AI Studio](https://aistudio.google.com/) | 官方一手 API，能力前沿 |

## TS SDK（按引入顺序）

| 包 | 章 | 说明 |
|---|---|---|
| `openai` / `@anthropic-ai/sdk` | 2·5 | 官方 SDK；配 base_url 即可调兼容端点 |
| `zod` | 5 | schema 定义，结构化输出的搭档 |
| `ai`（[Vercel AI SDK](https://ai-sdk.dev/)） | 6 | TS 应用层事实标准：streamText / generateObject / tool / useChat |
| `@modelcontextprotocol/sdk` | 8 | MCP 官方 TS SDK，写 server/client |
| OpenAI Agents SDK (JS) 或 [LangGraph.js](https://langchain-ai.github.io/langgraphjs/) | 8 | 8.8 框架对照实验用 |
| [pi](https://github.com/mariozechner/pi) | 8 | 极简 TS agent harness，源码小到能读完；毕业项目可选底座 |
| [Mastra](https://mastra.ai/) | 了解 | TS 原生 Agent 框架，知道有这选择即可 |

## 向量与存储（按章引入）

## 桌面开发（第 11 章）

| 工具 | 说明 |
|---|---|
| [Electron](https://www.electronjs.org/) + [electron-vite](https://electron-vite.org/) | 推荐：主进程 = Node，MCP/文件系统能力全 TS 直通 |
| [electron-builder](https://www.electron.build/) | 打包分发 |
| [Tauri](https://tauri.app/) | 备选：更轻更安全，但 Rust 核心对 MCP 生态不友好 |
