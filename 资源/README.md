## 使用原则

1. **每章只跟 1 个主教材**，其余当字典查——资源焦虑是学习第一大敌
2. 收录时标注状态：`📖 未读` `🔄 在读` `✅ 读毕`；读毕且觉得好的，写两行推荐语
3. 发现新资源先进各分册末尾的"待审区"，过三关再转正
4. 视频资源一律"选看"（本仓库主人的偏好：文字为主）；标 ⭐ 的是例外，值得破例
