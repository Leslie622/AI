# AI 学习仓库

> 从 0 到 1 系统学习 AI 与 Agent。终点：**一个自己动手写出来的 Agent 桌面应用**。
>
> 学习者：前端工程师（TS 熟练）· 方式：概念全景优先，按大纲推进，不排期

## 怎么用（三句话）

1. 主线是 [知识大纲.md](知识大纲.md)（11 章，节点标了【精】/【浅】/【了】——精=动手，浅=概念，了=知道即可）
2. 到 [学习/](学习/) 对应章节目录，按 README 的节点清单逐个学：读 → 写笔记/demo（放本章目录）→ 勾掉 checkbox
3. AI 协作规则见 [AGENTS.md](AGENTS.md)（任何 AI 会话开始前先读它）

## 仓库结构

```
AI/
├── README.md        ← 入口（本文件）
├── AGENTS.md        ← 给 AI 看的协作说明
├── 知识大纲.md       ← 唯一主线：11 章知识大纲（稳定的地图，无状态标记）
├── 学习/            ← 学习过程与产物（01–11 章，每章 README 含节点清单 = 进度记录）
│   ├── 01-全景与格局/ … 10-前沿与延伸/
│   └── 11-毕业项目/
├── 实验/            ← 可运行的实验工程（跨章节长期使用，如 first-call API 调用台）
└── 资源/            ← 素材库：课程 / 必读文章 / 工具链 / 信息源 / 术语表
```

## 原则

- 概念够用就好：不推公式、不精读论文，能讲清"是什么/为什么/何时用"即达标
- 一手资料优先：官方文档 > 成熟教程 > 二手转述；中文不够英文补
- 输出倒逼输入：每章有代码产出；讲不出来 = 没学会
