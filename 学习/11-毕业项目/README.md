# 11 · 毕业项目：Agent 桌面应用 【精】

> 综合交付。M1–M6 全是前面练过的零件，本阶段核心工作是**组装、打磨、上线**。

## 开工前

- [ ] **11.1 产品定义与竞品分析** — 建议第 1 章学完就写愿景草稿 v1（我的桌面 Agent 帮谁、解决什么问题、长什么样），随学习迭代；竞品：Claude Desktop / Cherry Studio / ChatBox
- [ ] **11.2 Electron 架构与选型** — Electron + Vite + React + TS（主进程=Node → MCP stdio/文件系统直通；Tauri 更轻但 Rust 核心对 MCP 生态不友好，备选）；agent 引擎：自研 loop（8.2）或基于 [pi](https://github.com/mariozechner/pi)——第 8 章学完再定

## 里程碑（每个半天到两天可交付，做完即勾）

- [ ] **M1 桌面壳** — Electron + 聊天 UI（移植第 6 章应用）
- [ ] **M2 模型接入** — 流式对话/多模型切换/System Prompt 设置/会话持久化
- [ ] **M3 工具系统** — 本地文件读写/剪贴板/网页抓取，带权限确认
- [ ] **M4 MCP 客户端 ⭐** — 连接任意第三方 MCP server，工具动态注册（成为"平台"的一步）
- [ ] **M5 知识库** — 选定目录做 RAG + 引用溯源（复用第 7 章）
- [ ] **M6 记忆与多步任务** — 长期记忆 + agent loop 执行多步任务（计划预览/进度可视化/可中断）
- [ ] **M7 上线** — 评测冒烟集（≥30 用例）/护栏与确认弹窗/electron-builder 打包分发给真实用户

## 毕业标准

- [ ] 应用分发给 ≥3 人独立安装使用
- [ ] 能连接 ≥2 个第三方 MCP server 并成功调用其工具
- [ ] 多步任务完整自主完成（读文件 → 检索笔记 → 写结果），过程可视化、可中断
- [ ] 评测集关键链路通过率 ≥85%
- [ ] 项目复盘：做得好/做得差/学到什么/如果重来
