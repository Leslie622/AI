1.1

AI ⊃ 机器学习 ⊃ 深度学习 ⊃ LLM

验收：画得出包含关系图，能给非技术人讲明白。

一句话总纲：这是四个逐层嵌套的同心圆——AI 是目标，机器学习是实现它的主流方法，深度学习是方法里最强的一支，LLM 是这一支里专攻语言的最新物种。越外越老、越宽；越内越新、越专。

点击每一层，看它与内一层的边界——结构就像嵌套的 div：外层包含内层。

逐层详解：每层记"它是什么 + 一条边界"

大部分人混淆这四个词，不是因为不懂定义，而是不知道边界在哪。边界，就是"什么东西属于这层、但不属于里面那层"。

① AI（1950s 起）：一个目标，不是一项技术

让机器做"需要人类智能的事"。关键词是实现手段不限：手写规则、暴力搜索、从数据学习，都算 AI。它是个目标领域，不是某种具体技术。

反直觉的点：不学习的也是 AI。1997 年赢国际象棋世界冠军的"深蓝"，下棋策略全靠人写规则 + 暴力搜索，完全不会学习——但没人否认它是 AI。

📍 边界深蓝是 AI，不是机器学习——因为它的规则是人写的，不是从数据学的。

② 机器学习（1980s 兴起）：把"写规则"换成"学规则"

传统编程：人写规则，规则处理数据，产出答案。机器学习把方向反过来：给机器看大量"数据 + 标准答案"，让它自己归纳规则。这是范式级反转，也是这门学科名字的由来。

用你最熟的场景类比：垃圾评论过滤。手写正则 = 传统编程——你能枚举的 case（"抽奖""加V"的变体）永远不够多；拿十万条历史评论 + 是否垃圾的标注去训练 = 机器学习——模型自己学到信号，包括你根本没想到的那些。

📍 边界随机森林、老一代垃圾邮件过滤器确实从数据学规律，但模型很"浅"、特征要人工设计——是 ML，不是深度学习。（它们今天仍在生产系统里大量服役：便宜、可解释。）

③ 深度学习（2012 爆发）：网络自己学特征

机器学习里用多层神经网络的一支，层数多所以叫"深"。核心突破只有一条：不用人工设计特征了。以前做图像分类，你得先写代码把图片变成"颜色直方图、边缘数量"这类特征再喂给模型（特征工程）；深度学习是原始像素直接进网络，中间特征自己学。

TS 类比：就像类型推断让手写注解大量消失——以前必须人工显式给出的东西，现在由系统自动推断。2012 年 ImageNet 图像识别比赛上深度学习碾压传统方法，是这波浪潮的引爆点（1.2 时间线还会回来）。

📍 边界Stable Diffusion 画图、AlphaGo、人脸识别都是深度神经网络——但它们不是"海量文本上的超大 Transformer"，所以不是 LLM。

④ LLM（2018 起）：深度学习里的"语言巨兽"

三个限定词缺一不可：Transformer 架构 + 海量文本训练 + 千亿级参数，并且把一切任务统一成"预测下一个词"（这句先混个脸熟，第 4 章拆解）。

你叫得出名字的 GPT / Claude / Gemini / Llama / Qwen / DeepSeek / GLM 全在这层。最后一个容易混的点：ChatGPT、Claude 是"产品"，在 LLM 之上还包了一层应用——你未来的毕业项目就在那层（1.4 产业链时回来收这个伏笔）。

📍 边界LLM 内部没有更小的一层了；它就是当前这张图的最内圈。

判断套路：三问定位法

拿到任何技术，按顺序问三个问题，比背定义有用：

  1. 它从数据学习吗？否 → 只是 AI（深蓝）；是 → 至少是 ML
  2. 它是多层神经网络吗？否 → 停在 ML（随机森林）；是 → 至少是 DL
  3. 它是文本上的超大 Transformer 吗？否 → 停在 DL（Stable Diffusion）；是 → LLM

常见误区清单（讲给别人时最常被问）

1.2

时间线 2017 → 2026

验收：能说出每个关键节点是什么、为什么重要。不用背年份，背"先后顺序 + 因果"。

先给一个阅读姿势：这条时间线不是"一堆热点回顾"，而是一条因果链——每一步都在为下一步创造条件。读完请能回答："为什么是这条链，而不是别的？"

2017.06

Transformer 诞生

Google 发表论文《Attention Is All You Need》，提出全新架构：处理每个词时直接"注意"句中所有词、按相关性加权，抛弃了旧架构（RNN）必须逐词顺序处理的限制。

为什么重要：① 训练可以大规模并行 → 第一次让"把模型做大"在工程上可行；② 对长文本的关联建模更好。此后所有主流大模型都是它的后代，九年了架构没换过。

2018

GPT-1 与 BERT：确立"预训练 + 微调"范式

OpenAI 的 GPT-1（生成式）和 Google 的 BERT（理解式）各自验证了同一套两段式打法：先在海量无标注文本上"预训练"学语言规律，再用少量数据"微调"到具体任务。

为什么重要：从此 AI 不再"一个任务训练一个模型"。后来证明，生成式（GPT）路线的天花板更高——它是你正在用的所有大模型的直系祖先。

2019 → 2020

GPT-2 → GPT-3：规模本身就是能力

GPT-2（15 亿参数）因"太危险"分阶段放出而成名；GPT-3（1750 亿参数，前代 100 倍）展示了两个惊人的现象：少样本学习（在提示里给几个例子就能换任务，不用重新训练）和 Scaling Law（砸规模就能稳定涨能力）。OpenAI 同期开放 API，"模型即服务"商业模式起步。

为什么重要：行业信奉的第一条规模化曲线就此确立：训练时算力换能力。军备竞赛的号角吹响。

2022.03

InstructGPT / RLHF：学会听人话

用人类偏好反馈（RLHF）微调模型，让它从"补全机器"变成"听指令的助手"。

为什么重要：ChatGPT 的直接前奏——最后一块拼图是"对齐"而不是"更聪明"。

2022.11.30

ChatGPT 发布：交互革命引爆一切

技术上没有新东西（GPT-3.5 + RLHF + 对话界面），但两个月用户破亿，史上最快。

为什么重要：这一步的革命在产品与交互，不在智能——把前沿技术做成了人人可用、人人想用的东西。全行业的资金、人才、关注度从这里开始指数加速。

2023.03

GPT-4：能力跃升 + 多模态起步

各类专业考试接近人类前排水平，开始接受图像输入，上下文扩到 32k。

为什么重要：第一次让大众感到"通用智能可能真的在逼近"，付费 API 市场被正式带热。

2023.02 → 07

LLaMA / Llama 2：开源潮从 0 到 1

Meta 开放模型权重，泄露版催生 Alpaca 等低成本复刻（几百美元微调出可用模型）；Llama 2 随后开放商用授权。

为什么重要：全世界第一次能"在自己电脑上跑大模型"。开源生态从零启动，后来的 Qwen / DeepSeek / GLM 都受益于这条路。

2023.06

Function Calling：模型学会调用工具

OpenAI 让模型按约定格式输出"我想调用哪个工具 + 参数"，而真正执行的是你的代码。

为什么重要：LLM 从"会说"升级为"会请求调用"——这是 Agent 应用的技术前提。你毕业项目的地基就是它（5.4 与第 8 章精学）。

2023

国产模型起步与合规框架

文心一言 3 月打头；8 月《生成式人工智能服务管理暂行办法》生效后，通义千问、ChatGLM、豆包等首批备案上线；开源阵营 Qwen / DeepSeek / ChatGLM 陆续开放权重。

为什么重要：中文生态与合规框架（备案制）成型，直接关系到你未来产品能否在国内上线（10.4 详谈）。

2024

多模态元年

Claude 3（3 月，首次全面对标 GPT-4）、GPT-4o（5 月，原生全模态、实时语音）、Gemini 1.5（百万 token 长上下文）、Sora（视频生成演示）。

为什么重要：模型从"只会文字"走向"能看、能听、能说"。今天这些全是旗舰标配——半年一年的领先，很快变成行业基线。

2024.09

o1：推理模型开辟第二条曲线

OpenAI o1 在回答前先生成长思维链，用强化学习训练"怎么想"。

为什么重要：确立了第二条规模化曲线：推理时算力换能力——训练规模之外，"让它多想一会儿"也能买来准确率。数学、代码、复杂规划大幅跃升。

2024.11

MCP 发布：Agent 连接万物的协议

Anthropic 发布 Model Context Protocol——模型连接工具与数据源的开放标准，被称为"AI 界的 USB-C"。2025 年 3 月 OpenAI 宣布支持，Google 跟进，成为事实标准（2026 年月 SDK 下载近亿次、生态服务器数千个）。

为什么重要：工具生态从"各家私有"走向"一次接入、处处可用"。你的 Agent 桌面应用大概率会直接用上它（8.7 精学）。

2024.12 → 2025.01

DeepSeek 时刻：效率 + 开源登上牌桌

DeepSeek-V3（12 月）以宣称约 558 万美元的训练成本做出旗舰级性能（对比业界普遍数亿美元）；R1（1 月）开源推理模型对标 o1，并用"纯强化学习"训练（R1-Zero）验证可行。App 登顶多国下载榜，NVIDIA 单日大跌约 17%——市场重估"算力 = 壁垒"的逻辑。

为什么重要：证明前沿不是只有"无限烧钱"一条路；效率工程 + 开源路线正式站上第一梯队。

2025

Agent 年：从"回答问题"到"完成任务"

编程 Agent 成为主力场景（Claude Code / Codex / Cursor）；各家 Agent 框架与协议混战；GPT-5（8 月）发布；MCP 生态爆发。模型开始能自主执行长任务：读代码库、改文件、跑测试、自我修复。

为什么重要：AI 的价值锚点从"聊天"转向"干活"——这正是你的课程主线（第 8 章）和毕业项目的时代背景。

2025.11 → 2026.02

旗舰换代潮：史上最挤的两个月

Gemini 3（11 月）、Claude Opus 4.5（11 月）先后发布；2026 年 2 月 Sonnet 5、GPT-5.3、Qwen 3.5、GLM-5、DeepSeek V4、Grok 新版同月密集登场。竞争焦点：推理能力、Agent 能力、成本效率；旗舰进入万亿参数（稀疏 / MoE）时代。

为什么重要：格局定型为"海外三强 + 中国开源阵营"（1.3 详谈），且开源与闭源的差距缩小到"版本级"。

2026 · 现在

你在此处

旗舰标配：多模态 + 长上下文 + 工具调用 + 可调推理。Agent 从 demo 走进生产，编程是第一个杀手级应用；MCP 成为连接标准；应用层机会正多。

为什么重要：地图已经清晰、基础设施已经就位——此刻入场学"构建 Agent 应用"，时机刚刚好。

三条主线（比记事件更重要）

架构停滞，工程爆炸

2017 年之后架构基本没变——九年卷的全是：数据、规模、训练方法、后训练（RLHF/RL）、推理策略。记住"所有大模型都是 Transformer 后代"就抓住了主干。

两条规模化曲线

① 训练时算力（GPT-3，2020）② 推理时思考（o1，2024）。每条曲线的发现，都打开一波能力跃升。第三条还没出现。

交互革命驱动落地

API（2020）→ 聊天（2022）→ 工具调用（2023）→ Agent（2025）→ 协议标准化（MCP，2024–26）。每次交互升级都创造一层新市场——你的项目在最新那层。

🧠 记忆钩子一句话串起全链：2017 定架构 → 2020 验规模 → 2022 爆产品 → 2023 开工具与开源 → 2024 加模态与思考 → 2025 起做 Agent → 协议定标准。为什么从 2017 算起？因为更早的 AI 史（深蓝、专家系统）都在 1.1 的外圈里，与 LLM 无直系血缘。
1.3

模型格局：闭源 vs 开源

验收：知道两大阵营的代表玩家、各自适合什么场景；能为"你的项目该用哪家"说出理由。

2026 年的格局一句话：海外三强（OpenAI / Anthropic / Google）+ 中国高性价比开源阵营（DeepSeek / Qwen / GLM 等），头部差距缩小到"版本级"，竞争焦点从参数规模转向推理能力、Agent 能力、成本效率。

闭源三巨头

OpenAI GPT-5.x 系列

  • 先发优势 + 生态最大，开发工具链最全
  • ChatGPT 在消费端统治力强
  • 多模态、语音、Agent 工具全家桶

适合：通用应用起步、要最大生态与资料时

Anthropic Claude 4.5 系列（Opus / Sonnet / Haiku）

  • 编程与写作公认第一梯队，Coding Agent 首选
  • MCP 协议发起者，安全对齐口碑好
  • 长文本与复杂指令跟随强

适合：编程助手、Agent 编排、严谨文字工作

Google Gemini 3 系列

  • 原生多模态 + 超长上下文
  • 免费额度大方，适合学习试错
  • 与 Google 生态（搜索 / Workspace / Android）绑定

适合：多模态应用、超长文档、低成本起步

开源 / 开放权重主力

Meta Llama

  • 西方开源旗手，研究与微调生态庞大
  • 注意：license 附加条款，并非完全开源
  • 2025 年后势头放缓（Llama 4 反响平平）

适合：英文微调研究、存量生态项目

阿里 Qwen 通义千问

  • 开源家族最全：尺寸、模态全覆盖
  • 多为 Apache 2.0，商用友好
  • Hugging Face 衍生模型数量全球第一

适合：中文自部署首选之一，全尺寸都能选

DeepSeek V4 / R1 系列

  • 性价比传奇：低成本训出旗舰性能
  • MIT 协议，接近完全开源
  • 开源推理模型（R1）的代表

适合：推理任务、成本敏感、私有化部署

智谱 GLM-5

  • 清华系全栈：模型 + 平台 + 编程工具
  • 开源权重 + 国内合规友好
  • （趣味：本 AI 助手的底层模型就是 GLM）

适合：国产化场景、中文应用、编程 Agent

还有一串值得知道名字的：Mistral（欧洲代表）、Kimi / 月之暗面（长文本起家、K2 开源）、xAI Grok（部分开放）、字节豆包（C 端强）。混个脸熟即可，不必深究。

⚠️ 概念澄清"开源"在 LLM 语境多指"开放权重（open-weight）"——只放模型文件；训练数据和训练代码通常不放。License 差异很大：MIT / Apache 2.0（真开源，随便商用）、Llama Community License（可用但有附加条款）、研究限定（不可商用）。选型前先看 license。

逐层拆解

① 算力层：军备竞赛里卖铲子的

玩家：NVIDIA（GPU + CUDA 软件生态）、台积电（代工）、ASML（光刻机）、SK 海力士（HBM 显存）。

GPU 之所以统治 AI，是因为神经网络的核心运算（矩阵乘法）天生可并行，GPU 上万个核心正好对口。NVIDIA 真正的护城河不是芯片本身，而是 CUDA——二十年积累的软件生态，全世界 AI 代码都默认跑在上面。

逻辑：不管哪家模型赢，训练和推理都得买卡——"卖铲子"的旱涝保收。这是 AI 热潮里最确定赚到大钱的一层。瓶颈常不在算力而在 HBM 显存带宽。

② 云 / 基础设施层：收水电煤钱的

玩家：AWS / Azure / GCP；国内阿里云、腾讯云、火山引擎。

生意：按小时租 GPU、托管模型做推理服务（MaaS，Model-as-a-Service）。

逻辑：云厂不需要赌哪家模型赢——模型层打得越凶，算力租得越欢。它与模型厂既合作又竞争：Azure 专卖 OpenAI，Google 自产 Gemini 自己卖。

③ 模型厂：智商的批发商

闭源阵营：OpenAI、Anthropic、Google DeepMind、xAI；国内字节豆包、月之暗面、智谱、MiniMax 等。商业模式 = API 按 token 计费 + 订阅（ChatGPT Plus / Claude Pro）。代价是天文数字的训练与推理成本，典型的高投入军备赛。

开源阵营：Meta、阿里、DeepSeek、智谱。权重免费放出，图的是生态位：行业标准话语权、人才、云服务与企业版收入。开源是手段，不是慈善。

④ 应用层：把"智商"变成"结果"——开发者的主战场

玩家：ChatGPT / Claude 桌面端（模型厂自营）、Cursor（编程）、Perplexity（搜索）、剪映 / 妙鸭（音视频图像）、以及各垂直行业（法律、医疗、客服、教育）的 AI 产品。

逻辑：模型是"新电力"，用户只为"解决我的问题"付费，不为模型付费。门槛不在训练模型，而在场景理解 × 工程质量 × 分发渠道——这恰好是软件开发者的舒适区，也是大多数人的机会所在。

⑤ Agent 平台层：应用的基建（你课程的主场）

玩家：编排框架（LangChain、LlamaIndex）、低代码平台（Dify、Coze、GPTs）、协议与生态（MCP）、工具与技能市场。

逻辑：当应用都以 Agent 形态出现，就需要公共基建：编排、记忆、工具接入、评测。第 8 章你会亲手拆这层。

钱怎么流（以及每层都想跨界）

用户付订阅费给应用 → 应用调 API 付费给模型厂 → 模型厂租 GPU 付给云 → 云买卡付给 NVIDIA。有趣的是每一层都在向相邻层渗透：模型厂做应用（ChatGPT）、云做模型（Gemini）、硬件做云（DGX Cloud）——都想把上下游的利润吃进来。

🧠 记忆钩子五层一句话：算力卖铲子，云卖水电煤，模型卖智商，应用卖结果，Agent 平台卖连接。

"我在哪一层？"——定位分析

  • 你的身份：前端 / TS 工程师；毕业项目：Electron Agent 桌面应用 → 明确落在应用层，并直接消费 Agent 平台层的协议（MCP）与工具生态。
  • 三大利好：① 轻资产，一个人 + 一台电脑就能开工；② TS 技能直接复用——API 调用、SDK、前端交互全是主场；③ 模型能力持续外溢，今天的 API 价格与能力就是红利本身。
  • 一个清醒剂：应用层没有模型护城河（大家用的是同样的模型），护城河来自场景理解 + 私有数据 + 工程体验。这也是为什么课程要把 4–8 章的原理与工程打扎实——那才是你区别于"套壳选手"的部分。
  • 你的第二身份：你不只是应用开发者，还是模型的重度用户（本仓库的工作方式就是证据）。懂模型的脾气（第 4–6 章），既能做好产品，也能用好工具。
1.5

AI 编程工具与用 AI 辅助开发

验收：理解 Coding Agent 的人机分工——AI 写代码 + 人工审代码（这也是本仓库的默认工作方式）。

三个时代：从"联想输入法"到"会干活的实习生"

① 补全时代 ~2021–2022

GitHub Copilot 自动补全：你写上文，它猜下文。单行、单块、单文件局部。

类比：输入法联想——快，但方向盘始终在你手里。

② 对话时代 2023

ChatGPT / Cursor Chat：描述需求 → 得到代码片段 → 自己复制粘贴。上下文靠手动喂。

类比：秒回的 StackOverflow——查得快了，落地还是纯手工。

③ Agent 时代 2024 底 → 现在

Claude Code / Codex / Cursor Agent 等：给它目标 + 上下文，它自己读代码库、改多文件、跑命令、看报错、自我修复，循环往复直到完成。

类比：从自行车换到带安全员的自动驾驶——你从司机变成安全员 + 导航。

核心工作流：五步循环

  1. 定意图——写清楚目标、背景、约束、验收标准。这是你最主要的工作，相当于写一份小 spec。
  2. 给上下文——相关文件、报错原文、项目约定。喂什么决定它干成什么样（这就是"上下文工程"，5.5 章深挖）。
  3. 让它跑——Agent 读库、改码、执行；大任务拆成小步，每步可检查。
  4. 人工审查——逐行看 diff，像审 PR 一样。这一步永远不能外包给 AI。
  5. 验证——跑测试、手动验一遍。不满意就带着反馈回到第 2 步。

为什么人工审代码不可省（4 个硬理由）

  1. 它会一本正经地错（幻觉）——编造不存在的 API、幻觉出热门但不存在的 npm 包（供应链攻击还真用过这招）。
  2. 它优化"看起来对"，你负责"真的对"——测试绿了不代表逻辑对，更不代表需求对。
  3. 安全责任在你——密钥硬编码、用户输入拼接进命令或 HTML、引入恶意依赖，出事都是你的账号、你的生产环境。
  4. 你是责任人——AI 没有执业资格也不会被追责；merged 的每一行代码都署你的名。

审查清单（每次合并前过一遍）

把指令写好的心法（喂饱你的 Agent）

  • 四件套：目标（做什么）+ 背景（在什么项目里）+ 约束（技术选型 / 不要动什么）+ 验收（怎么算完成）。
  • 大任务拆小——一次一个关注点，步子越小返工越便宜。
  • 喂原文——报错信息、接口文档、期望输出的示例，直接贴给它，别转述。
  • 先要计划再动手——复杂任务让它先列方案，你确认后再写码，返工率大降。
  • 投资"仓库说明书"——写一份 AGENTS.md / CLAUDE.md 放在仓库里，让任何 AI 进场即懂规矩，一次投入长期收益。
🧠 对照本仓库你此刻正在实践 1.5：AGENTS.md 就是上面说的"仓库说明书"（恢复上下文 / 协作规范 / 大纲纪律），章目录是产物落点，README checkbox 是进度。AI 负责"讲、写、生成"，你负责"读、审、决定"——这正是 1.5 说的分工。到第 11 章毕业项目，这套习惯会原样放大：你是架构师 + 产品 + 审查者，AI 是实现者。
