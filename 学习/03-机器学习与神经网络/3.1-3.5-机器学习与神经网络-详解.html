3.1

三大范式：监督 / 无监督 / 强化学习

验收：能说清三种范式各自"学习信号从哪来"、各举一个例子；知道 LLM 的两段训练各属于哪类。

机器学习的所有方法，按"学习信号从哪来"可以分成三大范式。这是整章最重要的一张地图：

① 监督学习 Supervised

  • 学习信号：带标准答案的题海——数据是成对的（输入，正确输出）
  • 垃圾邮件过滤：十万封邮件 + 人工标注"是/不是垃圾"
  • 图像分类：图片 + 人工打的标签

类比：有答案的刷题，做完对答案

② 无监督学习 Unsupervised

  • 学习信号：没有答案，自己找数据内部的结构
  • 用户聚类：一百万个用户没标签，自动分成"价格敏感型"“品质型"等人群
  • 异常检测：找出"和所有数据都不像"的点（风控）

类比：给你一筐没有标签的照片，让你自己按相似度分堆

③ 强化学习 Reinforcement

  • 学习信号：没有标准答案，只有奖励——试错，好的行为加分，坏的扣分
  • AlphaGo 自我对弈：赢棋 = 奖励
  • RLHF：人类偏好反馈调教 LLM（ChatGPT 对齐的关键，4.5 详讲）

类比：学骑自行车——没人能给你标注"每一步的正确姿势"，摔了就是负奖励

三大范式在本课程的出现点

范式一句话定义LLM 训练的对应阶段课程哪一站细讲

⚠️ 一个高价值细节LLM 的预训练常被说成"无监督"，更准确的名字是自监督（self-supervised）：答案不需要人工标注——把任何文本挖掉下一个词，这个词本身就是标准答案。标签是从数据里自动构造的。这是监督学习的变种，也是 LLM 能"吃下整个互联网"的根本原因：世界上几乎无限的无标注文本，瞬间变成无限免费的题海。记住这个词，4.4 会反复用。
🧠 记忆钩子分范式只看一个问题：学习信号是什么？有标准答案 = 监督；没答案找结构 = 无监督；只有奖励试错 = 强化。LLM = 自监督预训练 + 强化学习对齐。
3.2

神经网络最小模型：神经元 → 层 → 训练循环

验收：知道"学习 = 调参数"就够了。能讲出四个词：权重、激活、损失、梯度下降。

神经元：一个"加权投票机"

神经网络的最小零件是神经元，它做的事简单到出乎意料：

一个神经元 = 乘权重 → 求和 → 过激活函数 → 输出。仅此而已。

直觉版：判断"这张照片是不是猫"——耳朵尖度 × 0.6，圆眼程度 × 0.3，有胡须 × 0.5……加权加总超过阈值就投"是猫"。权重就是每个特征的重要程度，而"学习"就是不断调整这些权重。一个 GPT-4 级模型 = 几千亿个这样的数字（权重）。

TS 类比：每个神经元就是一个纯函数 output = activate(inputs × weights + bias)；整个神经网络 = 几百万个这种函数的嵌套组合。所谓"模型文件"，就是把这几十 GB 的权重数字存下来。

激活函数：为什么要"弯一下"

神经元求和是线性运算，而线性套线性还是线性——没有激活函数，一百层网络的效果等价于一层，只能表达"直线关系"。激活函数（如 ReLU：负数一律归零）引入了非线性弯折，网络才能拼出任意复杂的边界。

TS 类比线性运算像纯表达式，组合一万次还是表达式；激活函数相当于引入了 if 分支——有了"条件性"，表达力才爆炸。没有激活函数的深度网络，就像没有分支的编程语言。

层与深度：逐层抽象

神经元横向排成层，层与层之间全连接；层数多就叫"深"（深度学习的名字来源，呼应 1.1）。每一层都在上一层输出之上做新的加权组合，形成逐层抽象：识别图像时，浅层学"边和角"→ 中层学"眼睛耳朵"→ 深层学"这是一张猫脸"；处理文字时，字 → 词 → 短语 → 语义。这些中间特征没人教，全是训练自己长出来的（呼应 1.1③"网络自己学特征"）。

损失函数：给"错得多厉害"打分

损失（Loss）是一个数字，衡量模型这次预测错得有多离谱：预测"是猫的概率 0.9"而真实是狗 → loss 高；预测对了 → loss 低。训练的全部目标就一句话：调整参数，让所有数据的平均 loss 变小。

梯度下降：下山

loss 是海拔，参数是坐标。梯度 = 当前的上坡方向；训练 = 反复朝反方向挪一小步。

下山比喻（记住这个就够）：把 loss 想成海拔，模型的几十亿个参数想成你在山上的坐标。梯度告诉你当前位置朝哪个方向走是上坡，你就朝反方向挪一小步——重复几十亿次，最终滚到谷底，谷底就是"错得最少"的参数组合，训练完成。学习率 = 每步步子的大小：太大一步跨过山谷来回震荡，太小走到天黑也到不了谷底。不需要会算导数，"沿下坡方向微调参数"这个画面就是 3.2 的全部数学。

↺ 换一批数据，回到第一步——重复几百万到几十亿次。这就是"训练要上万张 GPU 跑几个月"的原因（1.4 的算力层赚的就是这个钱）。
🧠 与 LLM 的连接GPT 的训练 = 这个循环的超级放大版，只改了三样：任务统一为"预测下一个词"（3.1 的自监督）、网络换成 Transformer（4.3）、数据是近乎整个互联网的文本。循环本身一模一样。
3.3

训练 vs 推理

验收：说出两者的区别；回答"你今后 99% 的时间只碰哪一个？为什么？"（README 原题）
维度训练 Training推理 Inference
在干什么反复调参数，让 loss 变小用冻结的参数做一次前向计算，产出预测
何时发生一次性/阶段性（出厂前）日常、每一次提问
算力成本天文数字：上万 GPU × 几个月单次便宜：几秒 + 几厘钱
方向数据 → 改参数数据 + 固定参数 → 答案（参数不变！）
类比培养一名员工：读书十几年员工上岗干活：每天出活
🔑 最关键的一个认知模型文件 = 冻结的参数。所谓"下载一个模型"，就是下载几千亿个数字（权重）；所谓"用模型"，就是拿这些数字做前向计算。推理时没有任何"学习"发生——ChatGPT 不会因为和你聊天就变聪明，它的参数在你使用时一个都不会变。模型"越用越懂你"的错觉来自上下文（每次把历史带回去，4.7），不是学习。

成本直觉：为什么 AI 公司烧钱在训练、赚钱靠推理

  • 训练是巨额固定投资：前沿模型一次训练数千万美元起步（1.2 里 DeepSeek 用五百多万做出 V3 才那么轰动）。
  • 推理是规模化收入：每次调用成本几厘，乘以十亿次调用就是生意——API 按计费，1.4 产业链里模型厂的收入全从推理来。
  • 微调（finetune） = 小规模再训练，在已有参数上继续调，比从头训练便宜几个数量级（第 9 章讲 LoRA）。
🧠 回答 README 的验收题你今后 99% 的时间只碰推理。为什么？因为你的角色是应用开发者：训练是模型厂的事（1.4 产业链里隔着一整层）；你调 API = 租用别人的推理服务；就算第 9 章学微调，也只是偶尔的小规模训练。理解训练是为了看懂"模型的能力从哪来、边界在哪"（4.4/4.8），动手做的几乎全是推理。
🧠 顺便收两个伏笔① o1/R1 的"思考"= 推理时多算（多花推理算力换准确率），不是训练——1.2 的第二条规模曲线发生在推理侧；② 你在控制台看到的 reasoning_content 就是推理阶段生成的思考 token。
3.4

过拟合、泛化、数据集划分

验收：用"背题 vs 理解"的类比把过拟合讲给任何人听（README 原话）。

泛化：模型真正值钱的能力

泛化（Generalization）= 模型在没见过的数据上的表现。这才是训练追求的东西——在见过的题上表现好没有任何含金量，会做新题才算学会了。

过拟合：把题背下来了，规律没学会

过拟合（Overfitting）= 模型在训练数据上分数极高，在新数据上一塌糊涂。它没有学会规律，而是把训练集背了下来（连同里面的噪声和特例）。

  • 学生类比（README 指定）：只刷真题背答案的学生——真题 99 分，换一组数字就不会了。真正学会的学生 90 分，但新题也 90 分。
  • 前端类比：复制粘贴式编程——每个 case 都处理了（因为测试里出现过），但没有抽象出模式；来一个新 case 就崩。会抽象的代码才有"泛化能力"。
  • 反面是欠拟合：学得不够，连训练数据都学不好——题都没刷会。实践中大家更怕过拟合。

数据集三分：教学、模拟考、高考必须分开

训练集 ~70%
验证集 ~15%
测试集 ~15%
刷题（模型学习时用）模拟考（调超参用）高考（最终成绩，只考一次）

为什么要分？用同一份数据既当教材又当考卷，分数必然虚高——模型见过答案。更隐蔽的是"数据泄漏"：测试集的信息以任何形式混进了训练过程，成绩就作废。

LLM 语境下的过拟合

  • 数据污染：预训练语料里混进了某基准考试的真题 → 跑分虚高。LLM 评测的头号坑，看到"刷榜分数"先想这个。
  • "模型背住了训练数据"：LLM 有时能一字不差复述训练时见过的文章——这是过拟合的极端表现，也是记忆/版权/隐私争议的技术根源（10.4 治理话题的伏笔）。
  • 别混淆：温度调太高输出胡言乱语是采样问题（4.6），和过拟合无关。
30 秒自测某模型训练集准确率 99%，新数据上只有 70%——发生了什么？该怎么判断一个模型好不好？（答案：过拟合了；只看训练集分数没有意义，要看没见过的数据上的表现。）
🧠 记忆钩子背题 vs 理解。过拟合 = 背题（训练分高、新题拉胯）；泛化 = 理解（新题也稳）。教育模型的方式和评价模型的方式必须是两套数据。
3.5

CV / NLP / 语音 【了】—— 知道名字即可

验收：各一句话说清（大纲标注【了】，三五句话够了）。

CV 计算机视觉

看图：分类（这是什么）、检测（东西在哪）、分割（精确抠出边界）、生成（Stable Diffusion）。代表：人脸识别、自动驾驶感知。

NLP 自然语言处理

读字：翻译、摘要、问答、生成。代表：机器翻译、LLM。本课程的绝对主线——LLM 就是 NLP 的当代形态。

语音

听与说：识别 ASR（语音转文字，如 Whisper）、合成 TTS（文字转语音）。GPT-4o 的实时语音就是它的当代形态。

趋势一句话：三者正在合流——旗舰模型全都变成"一个大模型 + 多种模态输入输出"（2024 多模态元年，4.11），领域边界越来越模糊。知道这三个名字、知道主线在 NLP，本节就毕业了。

产出

本章产出实战：三问三答

README 产出："能给同事讲清三个问题"。下面是参考答案，先自己讲，再对照。
问 1：模型的知识存在哪里？
存在参数（权重）里——几千亿个数字。每个数字是一个"特征重要程度"，几十亿层组合出所有能力。模型文件就是这些数字的存档；加载模型 = 把数字读进显存，推理 = 用它们做前向计算。知识不在数据库里，不在这段代码里，就在这些数字本身。
问 2：训练和推理差在哪？
训练 = 反复"猜答案→算损失→算梯度→调参数"的循环（参数在变，成本天文数字，出厂前完成）；推理 = 用冻结的参数做一次前向计算（参数不变，单次几秒几厘钱）。类比：读书十几年 vs 上岗干活。你今后的工作 99% 在推理侧。
问 3：为什么模型要那么多算力？
因为训练 = 在几十亿维的参数空间里做几百万轮"下山"，每一步都要对海量数据做前向+反向计算——全是矩阵乘法，恰好是 GPU 擅长并行的事（1.4）。一次前沿训练 = 上万块 GPU 跑几个月；推理便宜但乘以十亿级调用量，也需要常年租用巨量 GPU。算力层的钱就是这样赚的。

Q1（3.1）三大范式各一句话 + 一个例子；LLM 的两段训练各属于哪类？
监督：从带标准答案的题海学（垃圾邮件过滤）；无监督：没答案自己找结构（用户聚类）；强化：只有奖励信号试错学（AlphaGo / 学骑车）。LLM：预训练 = 自监督（挖掉下一个词，答案自动构造）；RLHF 对齐 = 强化学习（人类打分当奖励）。
Q2（3.2）用"加权投票 + 下山"两个比喻讲清神经网络；激活函数为什么必须有？
神经元 = 加权投票机：各特征乘以权重（重要程度）求和，超阈值输出。训练 = 下山：loss 是海拔、参数是坐标，反复沿下坡方向挪一小步，谷底即训练完成。激活函数引入非线性——没有它，一百层等价于一层，只能表达直线关系（像编程语言没有 if）。
Q3（3.3）训练 vs 推理；推理时模型会学习吗？
训练：调参数让 loss 变小，一次性的巨额投资；推理：用冻结参数做前向计算，每次几秒几厘钱。推理时没有任何学习发生——参数一个都不变，ChatGPT 不会因为聊天变聪明（"越用越懂你"来自上下文，4.7）。
Q4（3.4）什么是过拟合？三份数据集各干什么？训练 99% / 测试 70% 说明什么？
过拟合 = 背题而不是学会规律（训练分高、新题拉胯）。训练集刷题、验证集模拟考（调超参）、测试集高考（只考一次）——教学和考卷必须分开。99% vs 70% = 典型过拟合，评价模型只看没见过的数据。
Q5（3.5）CV / NLP / 语音各一句话？本课程主线是哪个？
CV 看图（人脸识别、Stable Diffusion）；NLP 读字（翻译、LLM——主线）；语音听与说（Whisper、TTS）。三者正在合流成多模态大模型。
