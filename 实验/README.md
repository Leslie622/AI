# 实验

**可运行的实验工程**——跨章节长期使用，不随某章完结而过期。

| 工程 | 说明 | 起点 |
|---|---|---|
| [first-call/](first-call/) | LLM API 调用台，三种用法：**`npm run ui` 本地控制台**（实时调参、实时看 SSE 推送，自动开浏览器）；`npm start` / `npm run stream` 命令行模式；每次调用自动产出全量日志（Key 打码） | 第 2 章产出（first-call.ts） |

## 约定

- 每个工程一个子目录，自带 `package.json`；密钥一律放工程内 `.env`，不进代码、不外传
- 章节里的学习型小 demo 仍放对应章目录；只有"长期会反复用"的工程才进这里
- 新增工程后记得更新上面的表格
